 5. DOSYA YAPISI
================================================================================
  main.py            -> Orkestrator (--monitor / --run-once / --check / --url)
  config.py          -> Tum ayarlar (.env / ortam degiskenleri)
  monitor.py         -> RSS kanal tarama + fingerprint duplicate kontrol
  fingerprint.py     -> Icerik parmak izi (normalize + sure bucket + hash)
  downloader.py      -> RAM'e yt-dlp stream (canli ilerleme raporu)
  intro_detector.py  -> Intro bitis tespiti (SponsorBlock/silence/whisper/scene)
  render.py          -> render_final (intro+video concat), generate_preview,
                        generate_gif (ilk/son 10s)
  ffmpeg_utils.py    -> pipe/BytesIO ffmpeg yardimcilari + probe_duration_file
  thumbnail.py       -> Orijinal kapak indirme + 'Kapaklar/' klasorune
                        video basligi adiyla kaydetme (maks 80 karakter)
  title_generator.py -> AI (deterministik) ayarlar: aciklama + etiket ureteci
                        (baslik uretimi artik kullanilmiyor)
  uploader.py        -> YouTube upload + set_thumbnail + update_video_title
                        + set_privacy + publish_video
  telegram_bot.py    -> Bildirimler + interaktif yonetim (rename/thumb/publish)
  YouTube Intro.mp4  -> 2.17s, 1920x1080, H.264, 30fps, STEREO AAC 48kHz
  requirements.txt   -> yt-dlp, google-api-*, python-telegram-bot, whisper,
                        numpy, requests, isodate, Pillow
  setup_auth.py      -> OAuth2 kurulumu
  .github/workflows/run_bot.yml -> GitHub Actions ucretsiz cron
  data/processed.json, uploads.json, pending_clips.json -> durum dosyalari
  Kapaklar/          -> indirilen orijinal kapaklar (video basligi .jpg)
  client_secrets.json, token.json -> OAuth2 kimlikler
